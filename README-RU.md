# Lumipage Reader

Lumipage-reader - это легковесная и быстрая читалка текстовых документов для Android.

## Возможности

* Быстрое открытие документов (зависит от размеров документа)
* Чистый и интуитивно понятный современный интерфейс
* Малый вес приложения и исходного кода.

## Технические требования
* **Min SDK:** 23
* **Язык:** Kotlin/Java

## Сборка
1. Создайте клон репозитория
   ```bash
   git clone [https://github.com/music25054-prog/lumipage.git](https://github.com/music25054-prog/lumipage.git)
2. Откройте проект в Android Studio.
3. Соберите приложение и запустите его в эмуляторе или на настоящем устройстве.
