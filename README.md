# Lumipage

**Lumipage** is a fast and lightweight PDF reader for Android devices.

## Features
* Fast PDF rendering and smooth page scrolling
* Clean and intuitive modern UI
* Lightweight build with low memory footprint

## Tech Stack
* **Language:** Kotlin / Java
* **Min SDK:** 23

## Build & Run
1. Clone the repository:
   ```bash
   git clone [https://github.com/music25054-prog/lumipage.git](https://github.com/music25054-prog/lumipage.git)
2. Open the project in Android Studio.

3. Build and run on an emulator or physical device.
